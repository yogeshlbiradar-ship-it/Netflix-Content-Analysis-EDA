# Netflix Content Analysis — EDA

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Netflix dataset to understand content distribution, ratings, genres, countries, release years, and content addition trends.

## Objectives
- Analyze Movies and TV Shows available on Netflix.
- Explore content ratings, genres, countries, and release years.
- Identify content addition trends.
- Create visual dashboards.
- Generate actionable business insights.

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Plotly
- Jupyter Notebook

## Project Files
- `Untitled.ipynb` — Netflix dataset analysis notebook
- `Untitled1.ipynb` — Additional analysis notebook
- `Untitled3.ipynb` — Main project notebook

## Key Analysis
- Movies vs TV Shows distribution
- Ratings and genre analysis
- Release year trends
- Content addition trends
- Country-wise analysis
- Movie duration and TV Show season analysis
- Director analysis

## Conclusion
The project explores Netflix's content catalog using Python and visualizations. The analysis helps understand catalog patterns and provides a foundation for further data-driven research.
